# K-SMART

K-SMART is a Kannada-aware prompt optimization research project that compares prompt representations across tokenizers and local Ollama models.

## Repository structure

- `backend/core/` - installable prompt optimization library
- `backend/` - FastAPI service
- `frontend/` - React/Vite interface
- `evaluation/` - prompt datasets, experiments, metrics, and analysis
- `docs/` - architecture, methodology, API, and related-work notes

## Quick start

```bash
make setup
make test
make run-api
```
